# 原项目规则到通用层映射

> 本表用于证明“通用化”不是删规则。项目专属内容不机械搬入通用库，但其规则职责必须有通用承接点和新项目专属落点。

| 原规则职责 | 通用承接 | 新项目还须补什么 |
|---|---|---|
| 作者最高裁决、正文授权、冲突优先级 | `01_通用规则库/01_作者裁决与规则优先级.md` | `01_项目专属规则/00_作者最高裁决.md` |
| 世界观、宗教、异类、人类古史 | 事实证据分层＋世界观规则卡 | 本书具体世界规则和旁白权限 |
| 人物关系、声线、历史／现实原路 | 人物关系声线规则＋人物卡＋关系矩阵 | 本书逐人卡、称谓与改线 |
| 技术、工业、机构、安全 | 专业内容规则＋技术制度项目卡 | 本书材料、工具、人才、财源、权限、试验和代价 |
| 海洋、异域、新物种、长期航行 | 跨卷任务规则＋资料来源卡＋地点交通卡 | 本书航路、季节、语言、物种和任务日历 |
| 水利、灾害或其他超长专项线 | 跨卷台账＋技术制度卡＋事实变更检查 | 本书专项研究和逐卷推进节点 |
| 战争、反派、宗教大型仪式 | 情节因果规则＋专业安全规则＋项目专项规则位 | 本书敌我目标、反制、仪式和伦理边界 |
| AI、系统、异能、教育与知识演化 | 可选能力规则＋能力系统卡 | 本书能力来源、限制、秘密、淡化与落地闭环 |
| 双词典、中文母语、动态标题 | 通用语言规则＋对白词典＋旁白词典 | 本书角色声线、时代词和禁用词 |
| 时空、在场、身体、知情 | 通用时空硬门＋地点交通卡 | 本书地点、耗时、伤病和消息链 |
| 版本、TXT、索引、历史稿 | 通用版本存证规则＋卷终核验＋脚本 | 本书正式目录、卷末标记和交付规格 |
| 全卷流程、读者复读、逐句核验 | 4份流程硬规则＋核验模板库 | 本书当前状态、作者授权和每卷证据 |

原项目中的具体海洋、水利、战争、宗教、人物、历史年代和能力设定属于项目专属资产，不能被误称为所有小说通用规则；新项目若需要同类内容，必须从模板建立自己的专项规则。
