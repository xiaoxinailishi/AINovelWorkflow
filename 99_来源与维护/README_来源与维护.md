# 来源与维护

## 一、提炼来源

本模板库于2026-08-15从一套正在使用的长篇小说工程中只读提炼。提炼目标是保存可复用的文件链路、规则判断、双词典方法、逐句核验、版本存证和卷终流程；具体书名、人物、年代、世界观、剧情和作者裁决不进入通用层。

来源项目仍是其自身的唯一权威，本模板库不会反向修改或覆盖来源项目。

## 二、维护原则

1. 先修通用模板，再由具体项目决定是否升级；
2. 模板升级不得静默覆盖项目冻结版本；
3. 新增通用规则必须更新规则总索引、17份迁移清单、核验卡模板和初始化脚本；
4. 新增流程阶段必须同步入口流程图、阶段产物表、项目骨架和卷终核验；
5. 改脚本后必须做语法解析和临时项目实测；
6. 参考小说只能用于归纳语言风险与方法，不复制其受版权保护的表达。
7. 新增任何资产必须更新入口09号完整资产登记、03号源文件去向、逐文件SHA清单和验收报告；不能只放文件、不留登记。
8. `.obsidian/workspace.json`和`graph.json`等属于软件运行状态，会随界面操作改变；它们只进入Obsidian入库记录，不进入内容SHA清单。
