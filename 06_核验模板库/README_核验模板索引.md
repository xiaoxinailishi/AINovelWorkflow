# 核验模板索引

## 使用顺序

1. 新建项目时填[新项目初始化验收卡](10_新项目初始化验收卡模板.md)；每个新窗口先填[基线读取回执](11_新窗口基线读取回执模板.md)；
2. 细纲完成后填[细纲规则核验卡](05_细纲规则核验卡模板.md)；
3. 工作单元写完后填[全规则覆盖与章卷核验卡](03_全规则覆盖与章卷核验卡模板.md)和[工作单元逐句表](01_工作单元逐句核验表模板.md)；
4. 发生修改时填[修改记录](06_修改记录模板.md)，旧哈希立即失效；
5. 每五个工作单元做[连续性复盘](07_每五工作单元连续性复盘模板.md)；
6. 整卷工作单元完成后填[全卷连续性](04_全卷连续性与规则总核验表模板.md)，并用[章节存在性检查卡](12_章节存在性检查卡模板.md)判断保留、合并、拆分或删除；
7. 重组正式章后重新填[正式章逐句表](02_正式章逐句核验表模板.md)，不得继承工作单元结论；
8. 交付前填[卷终交付核验卡](08_卷终交付核验卡模板.md)；
9. 作者确认后填[作者扶正记录](09_作者扶正记录模板.md)。

跨项目提炼规则或模板时，另用[规则与资产来源筛选矩阵](13_规则与资产来源筛选矩阵模板.md)登记原样迁移、去项目化、项目专属、当前证据、历史记录和排除项。

核验表是证据，不是装饰。凡正文哈希、细纲版本或规则版本改变，受影响结论必须重新生成。

## 文件关联

- 本索引上游：规则总索引、每卷严格生产流程、逐卷写作与验收细则。
- 本索引下游：本目录全部核验模板及具体项目复制后的核验证据目录。
- 每一份由模板生成的核验文件，创建时必须填写自己的“文件关联”，不能只依赖所在文件夹。
- 核验文件至少要链接被核对象、同层证据和下一道闸门；不存在的未来文件只写普通文字路径。
- 正文、规则或设定变动后，必须沿关联链标记失效并重验，不能只改当前文件。
