# 核验模板索引

## 使用顺序

1. 新建项目时填[新项目初始化验收卡](10_新项目初始化验收卡模板.md)；每个新窗口先填[基线读取回执](11_新窗口基线读取回执模板.md)；
2. 卷纲常规检查后、细纲常规核验后，分别使用[周易思维三阶段复核卡](15_周易思维三阶段复核卡模板.md)完成卷纲复核，以及整卷＋逐W细纲复核；
3. 细纲完成后填[细纲规则核验卡](05_细纲规则核验卡模板.md)；
4. 工作单元动笔前先建立[全规则覆盖与章卷核验卡](03_全规则覆盖与章卷核验卡模板.md)并填完W写前固定区；写作中同步填写写中区；成稿后先锁候选SHA建立W独立周易复核，通过后才开始老书虫全文核验，再填写成稿后区和[工作单元逐句表](01_工作单元逐句核验表模板.md)；
5. 发生修改时填[修改记录](06_修改记录模板.md)，旧哈希、本轮周易卡和全部下游证据立即失效；对新SHA先重做周易，再从老书虫全文核验起完整重核；
6. 每五个工作单元做[连续性复盘](07_每五工作单元连续性复盘模板.md)；
7. 整卷工作单元完成后填[全卷连续性](04_全卷连续性与规则总核验表模板.md)，并用[章节存在性检查卡](12_章节存在性检查卡模板.md)判断保留、合并、拆分或删除；
8. 重组正式章后逐C锁候选SHA并先建立独立周易复核，不得继承W；通过后从老书虫全文核验起重新填[正式章逐句表](02_正式章逐句核验表模板.md)及全部C下游证据；
9. 交付前填[卷终交付核验卡](08_卷终交付核验卡模板.md)；
10. 作者确认后填[作者扶正记录](09_作者扶正记录模板.md)。

跨项目提炼规则或模板时，另用[规则与资产来源筛选矩阵](13_规则与资产来源筛选矩阵模板.md)登记原样迁移、去项目化、项目专属、当前证据、历史记录和排除项。

当作者与AI的写作、核验、放行或回写责任不明确，或准备变更协作方式时，先填写[常见协作模式配置模板](14_常见协作模式配置模板.md)。该配置只明确责任，不得削弱正式项目的证据链；任何模式下最终扶正都只能由作者作出。

核验表是证据，不是装饰。凡正文哈希、细纲版本或规则版本改变，受影响结论必须重新生成。周易复核不能代替常规核验，常规核验也不能代替周易复核。

强制文件矩阵、固定目录和总阻断条件见[每卷严格生产流程第三节](../00_模板库入口/03_每卷严格生产流程.md#三阶段输入输出和闸门)。任一必需文件缺失、错放、空白、待核、SHA不一致或关联不完整，禁止提交W、C或卷终验收。
