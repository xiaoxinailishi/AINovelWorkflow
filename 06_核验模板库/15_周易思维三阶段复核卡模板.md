|  |  |  |  |  |  |  |  |  | 待核 |

禁留事项至少包括危险警告、救命撤离、直接军令、医嘱与知情同意、罪证与定罪边界、契约核心义务、授权边界、灾情账目、补偿和交接。机密不等于含糊：接收人不必知道全盘，但其完成自身行动所需的信息必须完整。
