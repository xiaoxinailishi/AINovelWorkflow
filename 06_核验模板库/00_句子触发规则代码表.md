# 句子触发规则代码表

> 用法：先辨认句子在故事中的功能，再填所有实际触发的代码。代码只是索引，不能代替人工判断和上下文阅读。

| 代码 | 触发对象 | 必问问题 |
|---|---|---|
| G1 | 所有句子 | 中文是否自然完整；这句是否有故事作用；删掉是否更好？ |
| D1 | 对白称谓 | 亲属、上下级、公私场合和话语对象是否先于官爵判断？ |
| D2 | 年龄／身体对白 | 此人的年龄、伤病、疼痛、呼吸和当时动作允许说这么长、这么完整吗？ |
| D3 | 对白知情 | 他说的每项信息从哪里知道；是否把作者或读者所知倒灌给角色？ |
| D4 | 所有对白 | 是否像自然中文；有无漏“了、着、过”和中心词；是否提纲腔、翻译腔、AI腔？ |
| D5 | 家庭／闲谈／共同做事 | 是否被写成连续审讯；是否有共享前情、人情、动作、打断或真实语气？ |
| D6 | 重词／定性 | “妖、反、逆、通敌、祥瑞、天命”等首次出现有无说话人和来源？ |
| D7 | 所有对白／转述 | 是否按当前对白词典核过身份、对象、共享前情、语气、虚词、结果补语和说后动作；是否照抄参考书？ |
| A1 | 人物动作 | 人是否在场；身体、年龄、伤病、手中物和空间允许完成动作吗？ |
| A2 | 物件／换人 | 谁拿着、放在哪、何时交接；动作桥是否完整？ |
| A3 | 命令／处置 | 人物有无权限；命令通过谁执行；亲属关系是否被职位话术覆盖？ |
| A4 | 行动因果 | 前一句是否足以触发此动作；有没有突然转折、突然会意或作者代推？ |
| N1 | 旁白／内心 | 视角人物能否感知；旁白是否提前证明未知事实？ |
| N2 | 旁白解释 | 是否在替读者解释已经看懂的动作、气氛、性别价值或问话效果？ |
| N3 | 叙述语言 | 是否出现报告、政策摘要、现代管理、AI万能总结或英文语法式中文？ |
| N4 | 连续性／重复 | 是否复述上文、重复介绍熟人、重复首次信息或用同构句撑场？ |
| N5 | 所有旁白／内心／对白标签 | 是否按当前旁白词典核过报告腔、作者讲解、抽象总结、动作证据和故事必要性；是否照抄参考书？ |
| F1 | 新事实／信息 | 来源是谁、何时、通过何种文书、传话、观察或旧记进入本场？ |
| F2 | 新名词／伏笔 | 首提是否清楚；本章是否承接、追查或改变行动；若不承接是否应删？ |
| T1 | 时间／地点／路程 | 日期、时辰、位置、上下游、旅行和传信耗时能否成立？ |
| X1 | 历史／技术／医学／宗教／法律 | 是否符合作者锁定、事实双轴、时代词、现实前置和采用状态？ |
| Y1 | 周易复核：时位中正 | 这句在此时由此人说／做是否合身份、权限、身体和分寸；有无过与不及？ |
| Y2 | 周易复核：应比承乘 | 话与行动由谁接住、回应或反制；是否存在越位、承接不足或小力压大责？ |
| Y3 | 周易复核：几微变通 | 是否承接前兆和条件变化；有没有把推断当定论、把一套办法说成永远有效？ |
| Y4 | 周易复核：损益进退 | 谁受益受损；推进、等待、退让和停止线是否清楚？ |
| Y5 | 周易复核：言行终始 | 说话是否合时、合位、合知、合密、合诺；说后行动、传播、维护和下一始是否存在？ |
| Y6 | 周易复核：留与尽 | 事项是可留、慎留还是禁留；必须十分说／做到什么，可以保留什么，由谁判断，何时补齐，误判谁承担？ |

## 最低触发组合

- 对白：`G1+D1+D4+D7`；家庭、闲谈、照料再加`D5`。
- 动作：`G1+A1`；涉及接物、换人、移动加`A2`。
- 旁白：`G1+N1+N2+N3+N5`。
- 新信息、重词和新名词：在上述组合上加`F1+F2`，重词另加`D6`。
- 日期、路程、专业事实：加`T1`或`X1`。
- `Y1—Y6`只在W成稿／C重组并锁定候选SHA后、老书虫全文章节核验前的独立周易正文复核中调用。Y6是关键言行的零号分类；普通句不机械塞满六码，但复核记录必须回查具体W／C句号。后续核验若改文，须对新SHA先重做Y类复核，再从老书虫全文核验起重跑。

填`G1`不等于可以跳过其他代码；它只用于没有更具体触发项的普通句。
