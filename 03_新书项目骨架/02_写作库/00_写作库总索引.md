# 写作库总索引

严格顺序：全文母纲 → 全书年表 → 跨卷活动台账 → 当前卷卷纲 → 逐工作单元细纲 → 作者授权进入生产准备 → 当前卷执行包锁基线 → 细纲核验 → W正文 → 卷终重组C正式章 → 作者扶正 → 正式正文库。

| 目录 | 作用 | 正文前是否必须完成 |
|---|---|---|
| `01_全文母纲` | 全书承诺、阶段、结局 | 是 |
| `02_全书年表` | 时间、年龄、地点、事件 | 是 |
| `03_跨卷活动台账` | 跨卷任务出发、途中、回收 | 是 |
| `04_卷纲` | 当前卷功能和结果 | 是 |
| `05_细纲` | 逐W可执行场景链 | 是 |
| `06_当前卷执行包` | 作者已授权卷的生产入口 | 授权后建立 |
| `07_正式正文库` | 作者已扶正正文 | 卷终后 |
| `08_任务卡` | A/B/C/D、能力、技术、战争、宗教、插镜和敌手行动证据 | 按当前卷触发情况建立 |
