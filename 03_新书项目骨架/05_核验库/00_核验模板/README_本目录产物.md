# 核验模板目录

从通用模板库完整复制核验模板。项目只能补充字段，不得删除逐文件覆盖、逐句判断、修改失效、卷终和扶正门禁。

除逐句与卷终模板外，还必须保留：新项目初始化验收卡、新窗口基线读取回执、章节存在性检查卡和周易思维三阶段复核卡。项目若从旧工程或外部规则库迁移资产，还须保留规则与资产来源筛选矩阵。
