# 核验库入口

核验顺序：卷纲常规检查 → 卷纲周易复核 → 细纲常规核验 → 整卷＋逐W周易复核 → W成稿锁候选SHA → W周易正文复核 → 老书虫全文核验 → 小白／双词典／全规则覆盖／逐句核验与修改闭环 → 每五W复盘 → 全卷连续性 → C重组锁候选SHA → C独立周易正文复核 → 老书虫全文核验 → C小白／双词典／全规则覆盖／逐句核验与修改闭环 → 卷终交付 → 作者扶正。

所有核验必须绑定当前文件SHA。正文改变后，旧表不得继续标“通过”。

卷纲／细纲的周易复核是常规核验后的独立闸门；W／C正文的周易复核是老书虫全文章节核验前的独立闸门。不得起卦、占断或用卦名代替事实、人物与因果。W／C后续核验只要改文，旧周易结论与全部下游证据同时失效，必须对新SHA先重做周易，再从老书虫全文核验起重跑。
