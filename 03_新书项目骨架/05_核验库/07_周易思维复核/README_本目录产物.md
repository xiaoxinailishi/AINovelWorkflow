# 周易思维复核目录

按卷建立`第XX卷_卷名`子目录，保存卷纲、整卷细纲＋逐W、每个W正文和每个C正式章的独立周易思维复核卡。

卷纲／细纲固定顺序是“常规核验完成 → 锁定对象SHA → 周易思维独立复核”。W／C正文固定顺序是“成稿／重组完成 → 锁候选SHA → 周易正文复核 → 老书虫全文章节核验 → 小白／双词典／全规则／逐句核验”。后续任一步改文，本轮周易卡及全部下游证据失效；锁新SHA后先重做周易，再从老书虫全文核验起完整重核。

不得用卷级汇总卡替代逐W或逐C证据，不得起卦、占断、随机抽卡或让C继承W结论。

## 文件关联

- 上游依据：[核验库入口](../README.md)、[核验模板目录](../00_核验模板/README_本目录产物.md)、项目内周易思维三阶段强制复核规则。
- 同层互证：[细纲核验目录](../01_细纲核验/README_本目录产物.md)、全规则覆盖、逐句核验和修改记录目录中的当前对象证据。
- 下游使用：卷终交付核验和作者扶正记录。
- 对象、规则或SHA变化后回写：对应卷纲／细纲／W／C复核记录和下一道闸门。
