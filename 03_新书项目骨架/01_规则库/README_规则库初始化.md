# 项目规则库初始化

## 一、必须完整迁移

初始化时必须原样复制通用模板库的以下两层，不得摘抄、概括或只保留目录：

1. `01_通用规则库` → 本目录`00_通用规则`；
2. `02_语言与风格库` → 本目录`07_语言与风格`。

同时必须把模板库入口中的4份流程硬规则迁移到项目`00_项目入口`，并按项目命名为11、17、19、20号文件。它们和规则正文、双词典属于同一迁移验收，不得拆开处理。

复制后生成文件清单和SHA256。文件数、相对路径和哈希未登记完成前，项目规则库状态只能是“未初始化”。

## 二、项目专属层

作者裁决、世界观、人物关系、题材规则、禁写项与交付规格写入`01_项目专属规则`。项目专属规则可以提高或具体化要求，不得静默删除通用规则。

## 三、冲突处理

作者最新明确裁决最高。出现冲突时：

1. 记录原规则和新裁决；
2. 标出受影响文件；
3. 更新项目规则总索引；
4. 重跑受影响的纲和正文核验；
5. 禁止仅在聊天中宣布覆盖。

## 四、每次写作前

按项目规则总索引从首行读到末行，逐文件记录SHA、适用项和不适用理由。任何“已经记得”“上一窗口读过”都不能代替本次登记。
