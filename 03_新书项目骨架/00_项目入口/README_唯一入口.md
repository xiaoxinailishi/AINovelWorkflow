## 正文门禁

只有当“当前工作状态”明确记录作者已授权某卷进入生产准备，才允许建立当前卷执行包；执行包建立后必须在锁定基线上重做细纲核验，并完成整卷＋逐W周易思维复核，全部通过前不得写正文。每个W成稿和每个C重组后，必须先锁候选SHA建立独立周易正文复核，通过后才允许开始老书虫全文章节核验；C不得继承W。后续任一步改文，必须对新SHA先重做周易，再从老书虫全文核验起完整重核。任何聊天中的模糊继续都不能替代文件授权。
