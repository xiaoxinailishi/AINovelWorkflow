# 通用旁白去AI官方腔词典

> 参考语料范围：某部长篇历史网文第1—1505章，共分离出88,999条旁白记录。统计用于观察方法，不是所有题材必须复制的配额。  
> 用途：专门约束叙述者，不与对白规则混用。目标不是模仿原书所有口癖，而是学习它如何用短段、动作、物件、视角切换和即时后果代替分析报告。  
> 边界：参考书自身也有“看到、看着、觉得、不禁、皱眉、点头”等高频拐杖词，本词典会同时标出，不能把一种AI腔换成另一种网文模板腔。

## 一、旁白语料的实际节奏

### 1. 段落与句长

- 旁白记录：88,999条；
- 段落平均23.27字，中位数22字；
- 75%的旁白段不超过32字，90%不超过42字；
- 旁白句平均22.65字，中位数21字；
- 常见转场：“第二天”144次、“良久”139次、“回到家”132次、“半饷”59次、“就在此时”57次、“清晨”44次。

这种速度来自：

```text
一段只给一个动作或判断
重要对白单独成段
解释不连续堆三段
镜头很快从脸、手、门、马、旗切到后果
大场面用多次局部变化拼成，不一次概括完
```

### 2. AI旁白词极少

88,999条旁白中：

- “机制、闭环、赋能、维度、范式、路径、抓手、认知升级、值得注意的是、从某种意义上、在这样的背景下、风险边界、利益相关方、系统性、结构性、换言之”均为0；
- “体系”5次，“形成共识”1次，“这意味着”1次，“本质上”1次；
- “与此同时”13次，远低于AI常见密度。

所以“宏大题材必须使用宏大抽象词”并不成立。原书经常直接写一袋盐、一张地图、一面旗、一匹倒下的马，让读者自己连接大局。

### 3. 原书自身的旁白拐杖词

机械统计显示：

| 词 | 次数 | 风险 |
|---|---:|---|
| 看到 | 5,902 | 视角人物反复“看到”，容易像摄像头说明 |
| 看着 | 4,885 | 容易连续用“看着……说道” |
| 觉得 | 2,888 | 直接报告感受，削弱现场 |
| 心中 | 1,665 | 容易把内心写成作者说明 |
| 不禁 | 1,379 | 老式自动反应词，连续出现会机械 |
| 目光 | 1,106 | 易接“闪过、深沉、复杂”模板 |
| 点点头 | 1,079 | 人人同一种认可动作 |
| 突然 | 957 | 滥用会让所有事件凭空发生 |
| 想起 | 961 | 容易插入整段背景资料 |
| 此时 | 912 | 可用，但常是无信息过渡 |
| 皱眉 | 816 | 人人遇事只会皱眉 |
| 微微 | 787 | 常与笑、点头、眯眼组成模板 |
| 摇摇头 | 732 | 高频否定动作 |
| 眼中 | 635 | 易接“精光、寒芒、复杂” |
| 缓缓 | 600 | AI也爱用，慎用 |
| 愕然 | 377 | 高频惊讶词 |

结论：学习原书的短段和动作后果，不机械复制这些词。正式写作时，同一章“看着／看到／觉得／不禁／皱眉／点头”各自超过3—5次，就应检查是否能换成真正发生的事。

## 二、旁白的核心转换：从作者结论退回场景证据

AI旁白：

> 这一举措标志着新工业体系迈出了关键一步，也为后续建设奠定了坚实基础。

小说旁白：

> 第二根钢轨没有裂。  
> 掌锤的老匠蹲下去摸了半晌，忽然叫徒弟把昨日那根废轨也拖来。两根并在一起，新轨长出三寸，颜色也更深。  
> 实战型角色抬脚踩了踩：“先铺到营门。”

差别在于：

- 不宣布“关键一步”；
- 给出成功证据和旧失败；
- 让懂行者反应；
- 让下一步成为人物命令；
- 读者自行得出“铁路开始了”。

## 四、旁白段落的四种基本结构

### 1. 动作段

只写动作和阻力：

> 炮车陷进泥里。六名军士一起抬，左轮仍往下沉。实战型角色跳下马，把缰绳扔给亲兵。

不补：“他以身作则，极大鼓舞了士气。”下一段让更多人下马就够了。

### 2. 物件段

用物件承载制度：

> 新尺钉在门内，旧尺挂在旁边。掌尺的人每验一件，便在旧尺上划一道。

不补：“新旧标准的对比昭示着时代变革。”

### 3. 反应段

选一至两个人，不写“众人”：

> 财政型角色先看账，谋略型长者却看门外排队的军属。两人谁也没有接行动型统帅的话。

### 4. 后果段

章末不总结主题，留下已经改变的现实：

> 夜里第三批煤车到了。守炉人没叫醒技术型主角，只把车号添在册尾。

这就足以表现团队开始自行运转。

## 五、大场面旁白：怎样写出宏伟而不写成战报

### 1. 先给地形，再给人数

“十万大军”只是数字。宏伟感来自队伍如何占满地形：

- 前锋已经过河，中军仍未出谷；
- 炊烟从第一寨连到看不见的坡后；
- 炮队转弯时，后面的骑兵等了半个时辰；
- 号声传到右翼时已经变调。

### 2. 用三个尺度来回切

```text
统帅：地图、旗、预备队为什么不动
队正：缺两人、药包湿了、邻队旗倒
个人：手抖、马喘、耳鸣、找不到同袍
```

宏观一段之后必须落一次局部；局部连续两三段后再抬回统帅，读者才既看得大又感到真。

### 3. 让敌人也会判断

不要旁白说“敌人显然低估了守军”。要写：

> 敌帅数过三轮齐射，命人专在换药时吹号。第四轮却没有停，前排倒下的人才明白明军换了轮次。

敌人会学，主角的胜利才有重量。

### 4. 胜负由多次局部变化组成

参考顺序：

```text
斥候丢失一条路
→ 第一轮炮击未达预期
→ 一名将领轻敌
→ 侧翼出现缺口
→ 敌方底牌暴露
→ 预备队仍不动
→ 普通军士堵住半刻
→ 统帅终于放旗
→ 追击有明确停止线
```

禁止一句“在行动型统帅英明指挥下，军队迅速扭转战局”吞掉整场战争。

### 5. 战后至少写五项中的三项

- 点名与失踪；
- 收尸与伤员；
- 马匹、火药和粮；
- 俘虏怎么分；
- 谁抢功、谁瞒报、谁要承担错误命令。

## 六、行动型统帅旁白示例模块

本节只在项目存在行动型统帅、强势家长或最高决策者时采用；不得把角色标签直接复制成人设。

### 1. 不用形容词替他立威

少写：霸气、威严、帝王气、恐怖威压、千古雄主。  
多写：

- 他到场后谁站起来；
- 哪道旧令被撤；
- 哪支军队当夜开拔；
- 谁原本敢说的话咽了回去；
- 他认可后实际多了多少兵、铁或时间。

### 2. 行动型统帅必须亲自看

行动型统帅不是只坐殿批准。每个关键阶段至少一次：

- 微服看庄户；
- 入营看坏枪；
- 亲问伤兵；
- 在地图前判断路与季节；
- 骑马检阅或亲临一处危险。

### 3. 亲属线不用剖白

他对亲人的感情可以写在：

- 明知隐瞒却不拆穿；
- 把最难的差事交给他；
- 战后先问伤没伤；
- 公开处罚，私下给第二次资源；
- 临时改称呼；
- 别人攻击儿子时，先问证据而不是先信。

### 4. 改写死亡结局必须有前置回收

若作者决定改变某名重要人物原定或史实死亡结局，正文必须回收此前已经建立的条件，例如：

- 多年前建立的医疗、救援或风险记录；
- 提前铺设的运输、通信或组织能力；
- 多名相关人物各自承担的一项关键环节；
- 专业团队已经验证过的措施；
- 特殊能力若存在，只能在既定边界内辅助，不能凭空给神药或撤销代价。

如此，改命不是作者临时偏心，而是全书前置建设在一个肉身上的集中兑现。

## 七、技术、宗教、家庭三类旁白

### 技术戏

每场至少出现四项中的三项：

- 一件坏件；
- 一名有脾气的操作人；
- 一个可测结果；
- 一个受损者或新麻烦。

少写原理史，多写断口、煤灰、漏气、油、绳、刻度、噪声、烫伤和谁不肯认错。

### 道佛大场面

罗天大醮、水陆法会不能旁白一句“宗教仪式盛大庄严”带过。应有：

- 仪式空间：坛、幡、钟、灯、香、疏文、名册、水陆牌位；
- 声音层次：钟磬、诵经、风吹幡、军属哭声、杂役传话；
- 现实组织：粮、净水、如厕、医棚、走失孩童、无主亡者名册；
- 多种信念：真信者、求安慰者、借神佛谋利者、负责秩序者；
- 仪式后的现实后果：寺观网络接流民、发现失踪者、暴露假名册或引出政治争议。

禁止把道佛统一写成愚昧，也禁止由旁白证实所有神异。

### 家庭戏

家庭段至少完成一件事：

- 发现主人隐瞒的伤；
- 让某人改计划；
- 暴露孩子的新性格；
- 让政策后果落到女工、仆役、军属；
- 给下一场大战埋一个必须回来的承诺。

如果删掉家庭段不影响任何决定，它就只是休息，不是故事。

## 八、AI常用旁白句式黑名单与替代

| 默认检查句式 | 替代办法 |
|---|---|
| 这不仅是……更是…… | 删除前半，保留最具体后果 |
| 从某种意义上说 | 明确是谁的判断；不确定就不下结论 |
| 值得注意的是 | 直接写事实 |
| 在这样的背景下 | 用“第二天／河冻前／北门急报”切场 |
| 这意味着 | 写人物接下来的动作 |
| 毫无疑问 | 给证据或留异议 |
| 他清楚地意识到 | 写他改令、停手或追问 |
| 众人面面相觑 | 选两个不同反应 |
| 空气仿佛凝固 | 写声音、茶、帘或脚步停止 |
| 命运的齿轮开始转动 | 写一封信出门或一扇门关闭 |
| 历史会记住这一刻 | 写后世仍在使用的物件／习惯 |
| 为后续发展奠定基础 | 写下一批人已经来、下一道麻烦已经出现 |
| 局势变得愈发复杂 | 点名新出现的第三方和他要什么 |
| 双方展开激烈博弈 | 写钱、粮、人质、期限或第一步动作 |
| 事情远没有那么简单 | 直接给异常证据 |
| 嘴角勾起一抹弧度 | 写他为何笑、笑后做什么 |
| 眼中闪过一丝精光 | 写他盯住哪个漏洞 |
| 缓缓开口，语气坚定 | 删掉标签，让句子和动作自己承担 |

## 九、每章旁白自检

1. 本章是否至少有一件能摸到、听到或闻到的东西？
2. 是否连续三段都在解释，没有人物改变动作？
3. 是否用“震惊、复杂、欣慰、坚定”重复了已经写出的反应？
4. 群体反应是否全一样？能否挑两个人写不同动作？
5. 技术成果有没有坏件、操作人和代价？
6. 政策有没有具体受益者与受损者？
7. 战争有没有路、水、粮、旗、伤员或敌方判断？
8. 章末是否又写“这为未来奠定基础”？能否换成真实的新变化？
9. “看到／看着／觉得／不禁／皱眉／点头／微微／缓缓”是否过密？
10. 删掉最后一段总结后，读者是否仍看得懂？若能，删除。

## 十、可直接调用的旁白约束块

```text
【启用旁白去AI腔词典】
1. 旁白不替读者宣布意义；用物件变化、人物动作、资源调动和晚到后果证明意义。
2. 每段原则上只写一个动作或判断；长解释拆入争论、坏件、账目、命令和现场后果。
3. 禁止高频使用“这意味着、奠定基础、标志着、形成体系、深远影响、众人震惊、情绪复杂、空气凝固”。
4. 技术戏至少写坏件、操作者、可测结果、受损者中的三项；政策戏至少写钱粮、执行人、期限、受损者中的两项。
5. 大战在统帅、队正、个人三个尺度之间切换；敌人必须会判断和学习；胜后必须写追击停止线与伤亡善后。
6. 行动型统帅的威严用别人行为、军令和资源变化表现；父亲感情用称呼、托付和第二次机会表现。
7. 罗天大醮、水陆法会既写仪式声音与信仰，也写名册、粮水、医棚、杂役和宗教网络的现实作用。
8. 同章“看到／看着／觉得／不禁／皱眉／点头／微微／缓缓”各自过密时改写，不能从AI腔滑到网文模板腔。
9. 章末不写作者总结，留下一个已经改变的现实或即将到来的具体麻烦。
```

## 十一、同一材料的三次改写示范

### 1. AI汇报腔

> 经过多轮技术迭代，钢轨项目终于取得阶段性突破。这不仅标志着本国冶金体系迈上新台阶，也为未来蒸汽铁路的全面落地奠定了坚实基础。

问题不在内容错误，而在六个抽象判断连续替读者下结论：多轮、迭代、阶段性、标志、体系、奠定基础。现场没有人，也没有一根轨。

### 2. 只换成网文模板腔

> 技术型主角看着完好无损的钢轨，嘴角勾起一抹弧度，眼中闪过一丝精光。众人无不震惊，谁都知道，一个崭新的时代即将到来。

这仍然没有解决问题，只是把报告词换成“嘴角、精光、众人震惊、时代到来”。读者看不到钢轨经受了什么，也不知道下一步会发生什么。

### 3. 可用的现场写法

> 炮车第十次碾过去，新轨只在接缝处掉下一片薄锈。  
> 掌炉匠没欢呼。他趴下去摸了摸，又叫徒弟把第三根轨翻过来。三根轨背面，都刻着同一个炉号。  
> 测量型角色把炉号抄进册里。实战型角色已牵过第二辆更重的炮车。  
> 技术型主角站在路边，没有拦他，只让人先把围看的孩子赶远。

这里没有宣布“突破”，但给出了试验次数、损伤位置、批次线索、人物分工和新的风险。意义由读者自己得出。

## 十二、旁白与对白的分界

- 对白负责人物当下想要什么、拒绝什么、命令什么；
- 旁白负责人物没说出口却能看见的动作、环境阻力、时间流逝和话语造成的后果；
- 同一信息只出现一次。行动型统帅若已经说“最后一面旗不许动”，旁白便写旗在风里没动，不再解释“他保持了战略定力”；
- 旁白不能替人物补齐一段没说完整的演讲。人物故意只说半句时，让对方的动作或下一场后果补足；
- 对白词典与旁白词典可以同时启用，但不得把旁白的完整因果塞回人物嘴里。
