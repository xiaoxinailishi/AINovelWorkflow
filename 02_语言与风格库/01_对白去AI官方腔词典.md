# 通用对白去AI官方腔词典

> 参考语料范围：某部长篇历史网文第1—1505章，共分离出56,945条有效对白。统计用于观察方法，不是所有题材必须复制的配额。  
> 用途：约束各类长篇小说的人物说话，防止角色把大纲、项目报告和官方宣传稿直接念出来。  
> 边界：学习“短、直、具体、有身份、说完便行动”的方法，不照搬参考书主角的现代粗口、标志性台词、民族蔑称和网络梗。

## 一、对白语料告诉我们的事实

### 1. 长度和标点

- 对白平均20.14字，中位数15字；
- 25%的对白不超过7字，75%的对白不超过28字，90%不超过43字；
- 句末为句号22,292条、感叹号19,321条、问号10,630条、省略号4,354条；
- 高频说话动作是“说道、说、笑道、问、问道、喝、喊”，但正文真正有力处常用人物动作直接领句，不必每句加标签。

这说明原书不是没有长篇论述，而是多数现场先由短问、短令、反驳、打断和动作推动。人物只有在课堂、朝议或战前动员时才连续说长话。

### 2. 短对白承担的功能

语料中反复出现“杀”“好”“点火”“齐射”“滚”“何事”“为何”“来人”“让他进来”等极短句。可借的不是粗暴词本身，而是以下规律：

- 军令不解释理由；
- 皇帝先问最要命的一件事；
- 情绪越重，句子常越短；
- 同一场里有人问、有人反对、有人执行，完整逻辑分散在多人身上；
- 说完后马上有人走、拿、杀、试、查、关门或改变命令。

### 3. AI报告词几乎不进入对白

在56,945条对白中：

- “机制、闭环、赋能、维度、范式、路径、抓手、认知升级、形成共识、这意味着、风险边界、利益相关方、底层逻辑、本质上、与此同时”均为0；
- “体系”仅2次，“系统性”1次，“更重要的是”3次。

所以以后人物对白一旦连续出现“体系、机制、协同、路径、落地、抓手、赋能”，不是“古人不懂现代概念”的问题，而是人物已经被作者夺走了嘴。

| 人物 | 可归属对白 | 平均长度 | 12字以内 | 使用提示 |
|---|---:|---:|---:|---|
| 参考书主角 | 4,337 | 25.9字 | 26.0% | 能讲长理，也常用反问和讥刺把话压回实处 |
| 行动型统帅 | 728 | 21.4字 | 41.8% | 核心人物中短句比例最高之一，短问、短令尤其鲜明 |
| 成长型晚辈 | 787 | 25.2字 | 26.8% | 早期问得多，后期命令和独立判断增加 |
| 财政型角色 | 201 | 22.9字 | 30.8% | 句子较完整，常把争论拉回钱粮、后果和法度 |
| 实战型角色 | 139 | 21.9字 | 28.8% | 直接、好胜、爱逼出行动，但不是只会喊杀 |
| 家庭型角色 | 262 | 22.1字 | 30.2% | 从家中人、钱物和安全说起，少作宏大宣言 |
| 谋略型长者 | 18 | 19.2字 | 38.9% | 样本少，结论只取“少、稳、留白”，不可机械仿句 |
| 参考书文人 | 193 | 28.4字 | 19.7% | 明显更长，擅机锋、推论和文人讥刺 |

## 二、总转换法：把结论拆成五种现场话

AI习惯让一个人把整件事说完：

> 我们需要构建一套跨部门协同机制，确保技术路线得到有效落地。

小说对白应拆开：

> “铁谁给？”财政型角色先问。  
> 实战型角色把刀往桌上一放：“人我出，先让我试。”  
> 测量型角色翻过坏掉的轴：“同一把尺量的？”  
> 行动型统帅看向技术型主角：“几时能响？”

五种现场话分别是：

1. **问实物**：铁、煤、粮、药、路、马、坏件在哪；
2. **问责任**：谁签、谁领、谁守、谁偿命；
3. **问期限**：几日、入冬前、河冻前、下一炉；
4. **问代价**：会死几人、误几日农时、少多少赈粮；
5. **下动作**：先试十件、封门、拿账、换尺、再打一炉。

## 四、对白常见AI句式替换

| AI句式 | 为什么假 | 改法 |
|---|---|---|
| 这不仅是A，更是B | 像演讲结语 | 只说眼下最要命的B，A让别人反驳出来 |
| 真正的问题在于…… | 角色替作者总结 | 直接指出断路、坏账或尸体 |
| 从某种意义上说…… | 没有立场 | 有把握就断言，没把握就问 |
| 值得注意的是…… | 报告提示语 | 直接说值得注意的事实 |
| 这意味着…… | 抢走读者判断 | 让人物改命令 |
| 毫无疑问…… | 强迫认同 | 拿证据或让对手不服 |
| 我们应当进一步…… | 没人、没时间 | 改成谁现在去做什么 |
| 双方形成统一认识 | 抹平分歧 | 写某人仍反对但服从 |
| 我们必须加强…… | 没有具体动作 | 改成添几人、守哪门、查哪册 |
| 事情远没有那么简单 | 人工吊胃口 | 下一句直接给异常证据 |

## 五、从参考书可借的说话动作

这些不是原句照抄，而是其高频功能的转写：

| 参考书常用办法 | AI常会写成 | 后续应该怎么写 |
|---|---|---|
| 皇帝只问“还有几日粮” | 皇帝对后勤保障表示高度关切 | 让行动型统帅问一个能杀死全军的问题 |
| 将领喊“点火”“齐射” | 战斗正式进入关键阶段 | 军令落下就写炮手动作，不解释阶段 |
| 臣子把账推到面前 | 他以数据有力论证了观点 | 让对方先看见最难看的数字 |
| 家人发现伤口才追问 | 她敏锐察觉他情绪异常 | 写衣袖、血、药味或吃饭动作 |
| 对手先骂再开价 | 双方进行了激烈博弈 | 写价码、威胁和谁先移开眼 |
| 行动型统帅认可后直接给兵 | 皇帝对方案给予充分肯定 | 资源变化就是肯定 |
| 参考书主角用反问拆空话 | 他指出对方逻辑矛盾 | 问“谁出钱”“谁去死” |
| 争论被命令打断 | 最终形成共识 | 写还有人不服，但门已关、军已动 |

## 六、项目人物声线卡建立方法

下列是角色功能示例，不是固定班底。新项目必须按实际人物重新建声线卡，不得把“技术型、统帅型、财政型”等标签直接当人物性格。

### 技术型主角

- 若项目有现代知识或AI，内心可使用其允许的关键词；对外必须译成人、物、次序和试验；
- 年龄、身体与教育阶段会限制句长和表达方式，不能让儿童或伤者无条件长篇论述；
- 常用：“先试”“哪一批”“记下来”“拆开看”“谁见过”“再做一回”；
- 禁用：“建立闭环、完成技术转译、形成系统能力”。

例：

> “先别说能不能。把漏气的三只摆一排，我要看裂口。”

### 行动型统帅

- 行动者常用短问短令，身为亲属时未必擅长表白；
- 常问：还有几日粮？谁领兵？哪条路断了？若他死了谁接令？你瞒了什么？
- 公开与私下使用不同自称；越危险，句子通常越短；
- 认可常用给兵、给铁、给第二次机会，愤怒常用拿下、退下、再查。

例：

> “人救回来。寨也要。追到黑石沟便停。”

### 财政型角色

- 不先否定理想，先问钱粮、民夫、误农、明年和地方会不会把好法变成加税；
- 条件句多、怒吼少；一条财政事实可以让全屋安静；
- 常用：“银子从哪出”“明年呢”“少征多少人”“灾年谁开仓”。

例：

> “第四座炉若也开，秋后的赈粮从哪一本账出？”

### 实战型角色

- 先问能不能打、谁先上、几时验货；好胜而非只会喊杀；
- 说话直接，允许粗粝，但不能突然讲组织理论；
- 常用：“别绕”“给我”“雨里泡一夜再看”“我先带人试”。

例：

> “给我二百杆。泡一夜，明早还能响，我便认。”

### 测量型角色

- 问批次、误差、编号、来源和重复结果；
- 不写成阴恻恻的万能侦探，而是由反复核量发现问题；
- 常用：“谁量的”“哪一批”“差半分”“换尺再称”。

例：

> “前三根都短半分。尺没错，是下刀的人每次都斜了。”

### 医护型合作者

- 以病人、产妇、女工和真实身体反驳漂亮方案；
- 常问：“疼不疼”“流了多少血”“谁值夜”“她答应没有”“伤了算谁的”；
- 她不是温柔提醒人文关怀，而是能停药、停工和承担签字的人。

例：

> “织机快了一倍。她们几时吃饭？手断了算谁的？”

### 谋略型长者

- 话少、稳；谈人心、亡者、香火、名分和宗教被谁利用；
- 不每句打禅机，不负责准确预言未来；
- 他的一句话应让人回去做事，而不是只让全场赞叹高深。

例：

> “名册上若少一个无主军士，这场法会便只是做给活人看。”

### 成长型晚辈

- 幼年先问为什么、能否亲看；少年开始问谁承担、哪份记录可信；成年先下自己的判断，再请长辈挑错；
- 成长不是越来越像技术型主角，而是能提出技术型主角没想到的本地方案；
- 每名晚辈要有自己的经验和实词，不能全说同一套主角腔。

## 七、称呼和动作规则

### 称呼必须随场合变化

- 正式场合：按项目时代、礼仪和组织使用身份或职务；
- 家中：按亲属、排行、乳名和感情远近称呼；
- 军事／行动现场：按实际指挥链称呼；
- 工作场所：按专业分工、资历和日常习惯称呼；
- 宗教场所：按真实身份与宗派称呼，不能一个泛称包办。

关系变化优先用称呼表现，不再补一句“二人关系因此进一步加深”。

### 默认少用的对白标签

慎用：缓缓开口、沉声说道、语气坚定、眼神复杂、不容置疑地说道、嘴角勾起弧度、眸中闪过精光。

优先：

- 没抬眼；
- 把账推过去；
- 手仍按在刀上；
- 换了称呼；
- 没接那杯茶；
- 只问了一句；
- 说完便叫人进来；
- 话到一半停住；
- 把旧命令撕了。

## 八、写完对白后的扫描词

以下词可用于大纲与分析，原则上不进入人物嘴里；若出现，逐句检查：

```text
体系 机制 闭环 赋能 维度 范式 路径 抓手
底层逻辑 核心逻辑 顶层设计 系统性 结构性
协同 统筹 推进 落地 优化 迭代 赋权
认知升级 形成共识 利益相关方 风险边界
公共能力 知识发动机 世界自性 战略定力
资源整合 多维度 全方位 高质量
值得注意的是 从某种意义上 在这样的背景下
这不仅是 更重要的是 这意味着 毫无疑问
```

## 九、可直接调用的对白约束块

```text
【启用对白去AI腔词典】
1. 人物每句话只完成一个主要动作；长论述拆成提问、反驳、实物、命令和后果。
2. 把体系、机制、闭环、路径、协同、落地等词翻译成人、粮、银、路、马、伤口、证据、印、册、尺寸和期限。
3. 行动型统帅短问短令；财政型角色问钱粮与明年；实战型角色问实战；测量型角色问批次与误差；医护型合作者问身体与谁承担；谋略型长者问亡者、名分与谁借神佛说话。
4. 一场对话至少有一次动作或决定变化，禁止多人站着把大纲念完。
5. 称呼随公开、家中、军中切换；关系变化优先通过称呼、资源和托付表现。
6. 禁止照搬参考书主角式粗口、原书标志性台词和“滚、杀、拿下”的高密度表面风格。
```

## 十、同一件事怎样让不同人物开口

场景：第一批钢轨过了破坏试验，但多开一座炉会挤占赈粮。

> 技术型主角：“先把断口送来。三根都从同一处裂，才是法子错了。”  
> 财政型角色：“第四座炉缓一个月。先把秋粮入仓，我给你找另一笔煤钱。”  
> 实战型角色：“铺到营门。炮车来回走十趟，断了算我的。”  
> 测量型角色：“不是十趟。三种车，各十趟；每一趟记哪一根先响。”  
> 医护型合作者：“试车前先清路。上回那个孩子的脚，到今日还没消肿。”  
> 行动型统帅最后才问：“冬前能铺几里？”

若删掉人物名仍大体能分辨说话者，这场对白才算完成声线设计。若六个人都说“此事需要进一步验证”，就算换了六个“沉声道”，仍然只有作者一个人在讲话。
