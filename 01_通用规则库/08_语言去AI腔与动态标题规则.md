# 语言文字、去AI腔与动态标题规则

> 本规则必须与`01_规则库/07_语言与风格/01_对白去AI官方腔词典.md`、`01_规则库/07_语言与风格/02_旁白去AI官方腔词典.md`同时执行。09号文件是总规则，不能代替逐次完整读取两份词典。  
> 两份词典吸收了长篇小说语料精读所得的方法：对白要有身份并改变行动；旁白依靠物件、身体、空间和后果，不替读者宣布意义。  
> 只借叙事机制，不复制原作句子、口头禅、粗口、民族蔑称、人物关系或具体桥段。

## 一、总语感

1. 长篇可以宏大，句子仍要落到人、物、路、粮、伤、时辰和决定。
2. 人物不念大纲，旁白不写项目总结。完整逻辑分散在提问、反驳、坏件、账本、命令和后果里。
3. 多数现场对白一到两句完成一个动作；课堂、朝议、父子密谈可长，但中间必须有人打断、追问或改变动作。
4. 旁白段落一段原则上只承担一个动作、感官或判断。解释连续超过三段，要改进场景。
5. 历史、奇幻或异世界题材也不追求满篇仿古文。用目标读者顺畅的叙述承载题材称呼、物质生活、礼法和人物思维。
6. 每次独立读者复读都同时采用两把尺子：先当作读过上亿字小说的老书虫，检查套路、解释欲、虚假悬念、机械转场、重复信息和作者替读者下结论；再当作第一次接触本书的小白读者，检查人物、时间、地点、动作对象与前后因果是否一遍就能看懂。
7. “老书虫标准”不等于把文字写得冷僻、文绉绉或故意含混；“小白能懂”也不等于旁白把已经演出来的事情再讲一遍。正文须用清楚、自然、当代读者顺口的中文，把难处藏进人物行动与具体场景。

## 三、对白规则

### 3.1 五种有用对白

以下五种只用于刑问、议事、军务、工场、医案等任务驱动场景，不是全书对白模板。家庭相处、照料病人、安抚孩子、朋友试探和普通闲谈，还要允许关心、抱怨、打趣、回避、话说一半以及双方都知道而不必重说的前情。不得把每一场对话都写成问实物、问责任、下命令。

1. 问实物：铁、粮、药、路、马、坏件在哪里；
2. 问责任：谁领、谁签、谁守、谁偿命；
3. 问期限：几日、入冬前、河冻前、下一炉；
4. 问代价：死几人、误几日农时、少多少赈粮；
5. 下动作：封门、拿册、再打一炉、先试十件、传骑追回。

### 3.2 主要人物声线捷表

| 角色类型示例 | 说话落点 | 常见动作 |
|---|---|---|
| 技术型角色 | 哪一批、坏在哪、先试哪处、谁见过 | 圈图、翻坏件、让人复做、删掉无法满足的前置 |
| 行动型统帅 | 人、路、补给、伤亡、谁担、几时能成 | 看现场、撤令、给资源、当众担责 |
| 财政／民生型角色 | 钱从哪出、明年怎么办、普通人少担什么 | 推账、改期限、卡住过快扩张 |
| 实战型角色 | 现场能否用、坏了怎么办、谁先试 | 亲自压测、改变用法、替同伴抢险 |
| 测量／调查型角色 | 谁量的、哪一版、误差多少、谁最后碰过 | 换工具、封样、重画图、查传递链 |
| 医护／照料型角色 | 疼、血、值夜、同意、伤了算谁 | 停药、清场、翻记录、提出停止建议 |
| 谋略／宗教型角色 | 名分、亡者、恐惧、谁借信仰说话 | 观察细节、留半句、让人去查现实 |
| 成长型晚辈 | 为什么、谁承担、两个答案为何都不够 | 先观察、自己作答、请长辈挑错、逐渐独立行动 |

### 3.3 称呼变化

- 正式场合：按项目时代和组织使用身份、职务或礼仪称谓；
- 家中：按亲属、年龄、感情和地方习惯使用家人称谓；
- 军事／行动现场：按实际指挥链称呼；
- 工作场所：按专业分工、资历和日常习惯称呼；
- 宗教场所：按真实身份和宗派称呼，不用一个泛称覆盖所有人。

关系变化优先通过称呼、托付、资源和谁替谁担责表现，不补一句“二人关系进一步加深”。

称呼判断顺序固定为：**先看说话者与所指人物的亲属／婚姻／师徒关系，再看当前是私事还是公事，最后才看职位与身份等级**。同一句话内不得无理由混用两套关系：亲属私下问家事应使用家庭称谓；外人在正式回话时才使用公职称谓。

### 3.4 对白可以短，但不能被削成提纲

1. “对白短”只适用于疼痛、失血、喘息、战马飞驰、炮火、隔门急报等确实说不长的场合，不是全书人物共同的说话习惯。
2. 身体正常、时间允许时，人物应当把对象、缘由、条件和要做的事说完整。不能为了显得利落，把“她方才说的三句就够了。其余的由我们接下就行了”削成“她方才三句，够了。其余我们接”。
3. 需要安抚、劝告、解释风险或交代责任时，不吝啬必要文字。人物可以重复一个关键词、换一种说法、补半句人情话；只要每句话在推进理解，而不是重复水字。
4. 一两个字的独立句只有在改变节奏、动作或情绪时才保留。“她没有喊”“他没动”“无人答”若删掉不影响读者理解，就删除或并入下一句写清实际动作。
5. 对白不是规则条文。少用“只报、只认、只守、只管、不得、不可”连续排比；同一人物一口气下多条命令时，要有称呼、轻重、停顿和现实对象。
6. 不得省略自然汉语中承接完成、变化和语气所需的虚词。`往后也别谈带兵了`、`人已经送到了`、`话还没有说完`中的“了／到／完”等必须保留；删掉后像标题、提纲或英文直译，就应恢复。

### 3.5 家庭对白与正式问话分轨

1. 刑问、医问、军情急报可以连续核对事实，但每个问题必须来自上一条答案或可见证据，不能像作者拿着提纲逐项点名。
2. 父子、夫妻、兄弟姐妹已经共享的事情，不从头互相介绍；用称呼、半句话、动作和对方的接话补全。
3. 家人关心病情时，不要人人都问“何时、何人、是否、为何”。有人先看脸色，有人递东西，有人说宽心话，有人因着急问错，人物差异要落在说话方式里。
4. 一段对白连续出现三组以上“问一句—准确答一句”时，必须判断是否真在审讯、诊病或核军情。若不是，改成自然接话；若是，也要加入迟疑、记不清、复述偏差、动作和身份压力，不能人人像口供纸。

### 3.6 重词首次出现不得虎头蛇尾

1. `妖、逆、反、通敌、天命、祥瑞`等重词第一次进入正文时，必须让读者知道是谁先说、为何会说、谁听见以及它改变了什么。
2. 角色不能为了宣示自己理性，凭空说“谁也不许称妖”；若此前无人提“妖”，这句话本身反而替流言造词。
3. 重词若只出现一次，既无调查、误伤、关系变化，也无后续回收，直接删除；若要保留，登记到伏笔／读者期待台账并安排再次增义。

## 四、对白禁用／慎用词

以下词可用于大纲和分析，原则上不进人物嘴；出现即逐句复核：

```text
体系 机制 闭环 赋能 维度 范式 路径 抓手
底层逻辑 顶层设计 系统性 结构性 协同 统筹
推进 落地 优化 迭代 赋权 认知升级 形成共识
利益相关方 风险边界 公共能力 知识发动机
资源整合 多维度 全方位 高质量 战略定力
值得注意的是 从某种意义上 在这样的背景下
这不仅是 更重要的是 这意味着 毫无疑问
```

并非单词绝对不能出现，例如“路径”可指真实道路；禁的是抽象管理话语成串。

## 五、旁白规则

### 5.1 从结论退回证据

不写：

> 这一成果标志着新工业迈出关键一步，为后续建设奠定基础。

改写思路：让重车第十次压过轨面、接缝掉锈、老匠摸断口、记录员抄批号、实战人员拉来更重的车、负责人先赶走围观孩子。意义由读者自己得出。

### 5.2 四类基本段落

1. 动作段：写人物怎样做、哪里受阻；
2. 物件段：新尺、坏轴、湿药包、空粮袋承载制度；
3. 反应段：只选一两个人不同反应，不写“众人无不震惊”；
4. 后果段：章末留一个已经改变的现实或具体麻烦，不总结主题。

### 5.3 常见AI句式替代

| 默认句式 | 改法 |
|---|---|
| 这不仅是A，更是B | 删除判断，写B造成的动作 |
| 值得注意的是 | 直接给异常事实 |
| 在这样的背景下 | 用时辰、急报、河冻、门响切场 |
| 这意味着 | 写人物改令或资源移动 |
| 他清楚地意识到 | 写他撕旧令、停手、追回传骑 |
| 众人面面相觑 | 选两个人写不同动作 |
| 空气仿佛凝固 | 写茶凉、帘外脚步停、马不安 |
| 命运齿轮开始转动 | 写一封信出门或一扇门关闭 |
| 为后续奠定基础 | 写下一批人已来、仓里多了一格、旧尺被劈 |
| 局势愈发复杂 | 点出新来的第三方想要什么 |
| 事情没那么简单 | 下一句直接给反证 |

### 5.4 动作拐杖词

同章反复出现以下词，要检查能否换成真实动作：

`看到、看着、觉得、心中、不禁、目光、点点头、突然、想起、此时、皱眉、微微、摇头、眼中、缓缓、愕然、嘴角勾起、眸中精光`。

不是全部删除，而是不让所有人物只会看、皱眉、点头。

### 5.5 中文母语句法与反翻译腔

1. 叙述和对白都按中文习惯组织，优先使用自然的主谓宾、结果补语、数量和否定顺序，不照搬英语或机器翻译的语序、强调法和省略法。
2. 应写“一个字也没有少”，不写“少一个字也没有”；应写“她今夜只负责一件事”，不写“她今夜只守一件”；应写“其余的由我们接下就行了”或“把剩下的事接下来”，不写截断成提纲的“其余的由我们接”。
3. 少用翻译腔式否定排比：`没有先A，也没有B；她看的是C，是D，是E`。除非前后对照确有意义，直接写人物先做了什么、看见了什么。
4. 少用名词或数量词硬作句尾：`她只守一件`、`他们之间隔着三道`、`这是一个必须`。补足“事、门、手续、选择”等中文语义中心，或改成自然动词句。
5. 少用机械强调句：`她盯的是……`、`他要的不是……而是……`、`少一个字也没有`、`这一点很重要`。能靠动作和上下文说明，就不另搭强调框架。
6. 修改后朗读一遍，问三个问题：现实中的中国人会这样说吗？这句话不看前后文是否仍缺宾语或中心词？换成日常中文后是否更顺而不损人物身份？任一答案不对，继续改。
7. 古代语感不等于故意倒装、残句和半文半白。身份通过称呼、词汇、礼法和权力关系体现，句子本身仍须让现代中文读者一遍读懂。

### 5.6 不替读者解释已经发生的事

1. 前文已经用停手、转身、避路、压低声音或继续忙碌写清现场反应时，不再补`屋里人都停下了手里的活`、`没人趁这时候问话`、`众人这才明白`、`这话问得直`一类总括句。删去后读者仍能理解，就直接删。
2. 集体背景动作必须推动场景才写。真正要封门、让路、停工、伏地或撤人时，写清谁发令、谁先动、谁没听见；不能用一行“所有人都……”填转场。
3. 不因为担心读者没看懂，就在动作之后加一句作者讲解。需要补信息时，让人物追问、误解、改动作，或补一个能改变判断的物件和后果。
4. 人物的利落、冒犯、聪明、害怕、疲惫和偏见由说话内容及动作自己成立，旁白不贴`问得直、答得稳、安排得明白、显然害怕`等评语。
5. 女性、儿童、仆役、伤者和普通人入场，优先正面写他们正在做什么。应写`四个女孩也在忙碌`并立即落到各自动作，不写`四个女孩也没有闲着`、`她们并非毫无用处`、`连女孩也能帮忙`这种先贬低再肯定的句式，除非人物偏见本身就是当场冲突。
6. 读者不是等待旁白解释的学生。正文只交代读者无法从前后动作合理得知、而且会影响当前选择的信息。

## 六、技术场景语言

1. 脑内现代词只短暂出现，对外转换：
   - 甲醇火 → 木精无色火／无色醇火，民间冰火、冷火；
   - 活塞 → 筒塞、塞子，学院成熟后再定名；
   - 公差 → 许差、上下限、能否换用；
   - 感染 → 创口热、肿、腐、恶臭等症状；
   - 标准化 → 同尺、同样板、能互换。
2. 一场技术戏至少有坏件、操作者、可测结果、受损者四项中的三项。
3. 不连续讲原理史。用漏气、断口、煤灰、油、噪声、烫伤、工时、坏件和争执表达。
4. AI只列候选，真正原因由拆机、病案、田地或战场确定。

## 七、医药、产育与身体词

1. 医学词必须服从时代、地区、职业和说话人。现代题材可用现代术语；历史或异世界题材先查项目术语表，不能让所有人共享作者的现代词汇。
2. 相近旧称、俗称和现代概念不得机械画等号；先写可观察症状、病程和角色判断。
3. 生理与产育称呼按身份、地域和私密程度区分，不用所有人统一一种标准说法。
4. 古医、民间病名或幻想世界病名不能机械一一翻成单一现代诊断；保留不确定性和误判空间。
5. 统一记录时仍保留地方异名，用主称＋异名＋可观察症状，不以消灭民间词为进步。

## 八、宗教、修行与超自然场景语言（可选）

1. 项目存在真实修行或超自然力量时，先写可见现象：呼吸、步伐、风、灯、身体反应、群体情绪变化；旁白不弹出“境界升级”。
2. 高人说象与趋势，不报完整未来；同一卦可有两解。
3. 大型仪式既写声音、器物、服饰和场地，也写名册、粮水、医疗、卫生、走失者和杂役。
4. 不把宗教人物写成统一愚昧，也不把每名修行者都写成高人。

## 九、家庭与感情场景

每个家庭低场至少改变一件事：发现伤、修改计划、暴露孩子性格、让政策代价落到家人／仆役／军属、立一个必须回来的承诺。删掉后不影响任何决定的纯闲聊要压缩。

核心感情线应来自共同经历、互相挡错、允许彼此拥有独立目标和日常亲密；是否使用误会、第三者或分裂，必须服从作者裁决，不能作为默认加戏工具。

## 十、工作稿不设字数，正式章在卷末重组

### 10.1 工作章节不设篇幅门槛

- 依原细纲生成的工作章节不设最高字数、最低字数或目标字数，也不按场景分配字数指标。
- 工作单元写到细纲规定的行动、选择、阻力、后果和下一接口完整为止；短而完整不灌水，长而必要不腰斩。
- 工作名单元只是生产边界，不是最终章界。一个工作单元可以拆成多个正式章，多个工作单元也可以合成一个正式章。

### 10.2 每个工作章节写完立即做读者复读

1. 暂时放下细纲、规则解释和“作者本来想表达什么”，只打开当前小说文本。
2. 从工作名／首行读到最后一个字，中途不以字数扫描、禁词结果或“细纲已经写了”替代阅读。
3. 先按普通读者感受记录：哪里看不懂、哪里想跳过、哪里像工作汇报、哪句对白不像人在当场说话、哪段重复解释、哪处情绪没有铺垫、章尾是否强行点题。
4. 再回到规则层检查时空、身体、知情、因果和时代词，修改正文后重新从头读一遍。
5. 当前工作章节没有复读通过，不得生成下一工作章节。写作中随手自检不算这次独立复读。
6. 复读顺序固定为：老书虫体验审读 → 小白可理解审读 → 规则审读。老书虫审读专抓套路、显而易见的旁白解释、人物被作者评价、重复场景和为了过桥硬加的集体反应；小白审读只补理解所需的自然信息，不得把删掉的讲解腔重新加回。

### 10.3 全卷重组后的正式章节

- 全卷工作稿完成并核对连续性后，再按自然场景、转折、选择和后果重划正式章界。
- 正式章节有效正文必须为{{正式章字数下限}}—{{正式章字数上限}}字；标题、元数据、注释和作者说明不计入。
- 先按故事边界合并、拆分和重写转场，再检查字数；不能先每三千字机械落一刀。
- 不足`{{正式章字数下限}}`的余尾须与相邻内容重新组章或补足真实缺失因果；超过`{{正式章字数上限}}`须在自然转折处分章。禁止用百科、重复心理、轮流表态和主题总结凑字。
- 正式章形成后，还要再次以读者身份从标题读到最后一个字；工作稿阶段通过不等于正式章自动通过。

### 10.4 每个叙事单元仍要有故事运动

工作单元和正式章都不能只是资料堆放。应完成若干真实变化，例如：

- 新问题被具体化；
- 人物作选择；
- 方案被反驳／失败；
- 资源、权限、关系或信息改变；
- 长任务状态推进；
- 出现必须由后文接住的新后果。

可用节奏是`带问题入场 → 行动 → 反证／代价 → 选择 → 执行 → 后果`，但不得机械复刻。战争、家庭、远航、仪式、侦查和技术场景各有自己的呼吸。

### 10.5 防灌水与防压缩

- 同一信息不在旁白、对白、内心各说一遍；
- 回顾前文只提当下决定所需的一两点；
- 群像不用轮流表态；
- 技术原理只讲当前变量；
- 章末不加主题总结；
- 不因工作稿过长而把动作砍成摘要，也不因工作稿过短而追加无效生活片段。

## 十一、卷名必须来自实际卷纲

1. 先完成该卷的进入状态、主问题、人物表、章节群、高潮、卷末不可逆结果和下一卷接力，再拟卷名；不允许先造一个雅词或冷词，再逼故事去解释它。
2. 卷名面向第一次打开目录的普通读者，应当一眼看懂核心人物、核心行动或最大转折中的至少一项。
3. 优先采用“人物／对象＋动作或处境”，例如`旧宅里醒来的孩子`；慎用只写气氛、内部代号、冷僻专名或只有设定作者才懂的隐喻。
4. 卷中出现某个专业词、工具或典籍，不代表它就是整卷主线。题材词负责正文质感，卷名负责告诉读者这一卷讲什么。
5. 每份逐卷细纲完成后拟3—5个卷名候选，按“准确、易懂、记得住、不泄底”四项筛选；确认后同步母纲、年表、细纲文件名与标题、必读映射、索引。
6. 卷名在卷纲阶段确定；章节名仍然必须等各章正文完成后动态生成，二者不得混淆。

## 十二、动态章节名

1. 按原细纲生成工作稿时只用内部工作名，如“样品第二次折断”“船长决定暂不返航”，不定正式章名。
2. 全卷连续性核对并完成正式章拆分／合并后，才从该正式章实际内容提取最强物件、动作、反差、决定和代价。
3. 拟3—5个候选，优先短、具体、有画面，避开空泛“新的时代”“命运转折”“帝国崛起”。
4. 标题不能泄露本章结尾底牌，也不能与前章重复同一结构。
5. 选定后再改文件名、章首、索引和台账。
6. 每卷最后一章标题末尾加 `{{卷末标记}}`，例如：`第087章 风停在黑旗之后（第十三卷结束）`。

## 十三、章末规则

优先留下：

- 一个新命令已经出门；
- 一件坏物暴露不同原因；
- 一个人换了称呼；
- 一条长任务传来迟到消息；
- 一份名单少了一个人；
- 新道路上出现第一辆普通人的车；
- 敌方学会了本方方法。

禁用：“谁也不知道，一个崭新的时代已经开始”“这为后来奠定坚实基础”等作者总结。

## 十四、交付前语言扫描

1. 人物是否说了身份不该懂的现代管理词？
2. 六个角色删去名字后是否仍有声线差异？
3. 本章是否“体系、机制、推进、落地、闭环”等分析词过密？
4. 是否连续用皱眉、微微、精光、众人震惊？
5. 技术、政策、战争是否各有具体物件与代价？
6. 产育是否误用“羊水”？
7. 古医词是否被机械翻成现代唯一诊断？
8. 章末删去总结后是否仍懂？若懂，删。
9. 标题是否在正文后生成？
10. 卷末章是否加卷结束标志？
11. 卷名是否真由本卷细纲得出，并让未读设定的读者看得懂？
12. 当前文本是否已经脱离细纲和作者解释，以普通读者身份从首行读到末字？
13. 哪一处最想跳读、最像公文、最不像人物当场说话？若没有逐项回答，不得只写“已去AI味”。
14. 是否出现“少一个字也没有”“只守一件”“其余我们接”等缺中心词、倒置否定或翻译式省略？必须改成自然中文后再朗读。
15. 是否出现`屋里人都停下了手里的活`、`没人趁这时候问话`、`这话问得直`等替读者解释现场的句子？删掉以后仍懂就删除；确有信息作用则改写成具名人物的动作或选择。
16. 是否用`也没有闲着、并非毫无用处、连她也能`先压低女性、儿童、仆役或普通人，再施舍式肯定？改为正面行动，除非这种偏见由具体人物说出并承担后果。
17. 老书虫是否能看出作者在机械铺垫、重复解释或强造悬念？小白是否能在没有设定表的情况下认清谁在何处做什么？两项必须分别记录，不得用一句“读起来顺”代替。
18. 是否把所有对白都压成一两句命令？身体与场合允许时，人物有没有把缘由、条件和人情说完整？

## 十五、双词典写前、写中、成稿后强制调用

1. 详细执行统一见`01_规则库/07_语言与风格/00_双词典强制调用说明.md`；本节只锁住语言规则中的不可省略项。
2. 每个新工作单元动笔前，完整读取当前执行版对白词典和旁白词典，在W表记录路径、SHA、读取时间和本章风险；没有记录不得动笔。
3. 写作中，对白直接参照对白词典，旁白直接参照旁白词典，夹叙夹议、转述、对白标签和内心句同时参照两份；写中参照不能代替成稿后独立审核。
4. 成稿后重新打开两份词典，先只审全部对白，再只审全部旁白，最后审二者边界。每轮必须记录具体发现和修复，不得只写“已去AI腔”。
5. `了、着、过、呢、吧、啊、才、才行`与结果补语按动作完成、状态变化和现场语气判断，不设数量指标。机械添加和机械删除同样不合格。
6. 正式章由工作单元重组后，重新执行成稿后双词典专审，不继承W表结论。
7. 本规则生效前的正文若只做成稿后追补，写前、写中必须注明历史阶段未执行；若作者明确命令正文重新进入完整复核重写周期，则从本轮写前真实读取双词典、写中逐章校订、成稿后专审、正式章独立重审，四阶段留证后可写“本轮已执行”，但禁止改写成初稿生成时已经执行。
8. 正文修改后，原双词典核验结论和SHA失效；修完必须重审受影响场景、全文对白、全文旁白并从标题读到末字。
