# 周易思维三阶段强制复核规则

> 状态：通用硬规则。
> 适用对象：每一卷卷纲、每一卷整卷细纲、每个W工作单元细纲、每个W工作单元正文、重组后的每个C正式章。
> 核心边界：本规则以《周易》的时、位、中、正、应、变、进退、损益、几微、终始与言行戒慎复核小说，不起卦、不占卜、不预测吉凶，不用卦名代替作者裁决、项目事实、人物卡和专业证据。

## 一、三阶段固定落点

每一卷必须执行独立周易思维复核。卷纲、细纲的落点在各自常规核验完成后；W正文、C正文的落点则提前到老书虫全文章节核验之前：

1. **卷纲阶段**：卷纲完成母纲、年表、跨卷台账、人物和事实一致性检查后，对整卷时势、人物位置、因果消长、进退节奏、损益承担、高潮转化和卷末接口复核。未通过不得把卷纲标为定稿，也不得据此放行细纲。
2. **细纲阶段**：常规细纲核验完成后，先复核整卷W链，再逐个复核每个W的时空、人物资格、场景因果、知情传播、代价、言行分寸、场末变化和下一接口。任一W未通过，整卷细纲不得放行正文。
3. **正文规则校验阶段的前置闸门**：每个W成稿、以及重组后的每个C，先锁定候选SHA并做独立周易正文复核；通过后才允许开始老书虫从标题／首行至末字的全文章节核验，再依次完成小白、双词典、全规则覆盖、逐句核验和必要修改闭环。C不得继承来源W的周易复核结论。后续任一环节只要改文，当前周易卡与全部下游证据同时失效，必须对新SHA先重做周易，再从老书虫全文核验起完整重核，直至所有证据共同对应最终SHA。

长篇项目必须逐卷、逐W、逐C执行。正式短篇若不设卷，仍须对全篇大纲、逐段／逐场细纲和每个正式章执行同等复核。轻量练习稿可以不生成正式证据，但必须标明“未执行周易思维正式复核”，不得冒充正式通过。

## 二、零号判断：不是都留三分，而是先判能不能留

本库用“说话留三分，做事留三分”概括不说满、不做绝、保留回旋与纠偏的分寸意识，但它不是统一比例。每个关键言行先回答：

```text
此人、此时、对此对象，这件事允许留吗？
必须十分说清／做到的是什么？
可以保留的是什么，保留到何时？
由谁作出分类，他有无知识、权限和在场条件？
判断错误时，谁承担何种后果？
```

| 分类 | 适用范围 | 必须满足 |
|---|---|---|
| 可留 | 情面、试探、议价、谋略保密、证据尚未成熟的判断、分阶段试验、可逆试点 | 方向、必要事实、当前责任和停止线已说清／做到；保留内容、补齐时点和风险承担者明确 |
| 慎留 | 同一事项兼有公开与机密、确定与未知、立即义务与后续选择 | 先把会影响对方判断与行动的事实、风险、责任和停止线说足，只保留不影响当前决策的部分 |
| 禁留 | 危险警告、救命撤离、直接军令、医嘱与知情同意、罪证与定罪边界、契约核心义务、授权边界、灾情账目、补偿和交接 | 对相应责任对象必须完整、准确、可复述、可执行并留证；不得以含蓄、保密或“留三分”制造职责缺口 |

机密不等于含糊。执行者可以不知道全盘战略，但其目标、动作、时限、优先级、停止线和失联备线必须清楚。允许分阶段做七分，也必须形成一个可核验、有成果、有停止条件的阶段，不能把偷懒、烂尾或转嫁风险包装成分寸。

## 三、常核十八镜

每个正式复核对象必须逐项判断。可以写“不适用”，但必须给出当前对象级理由。

| 镜 | 必问问题 |
|---|---|
| 时 | 为什么此时发生；季节、年龄、病程、行程、信息延迟和任务周期是否成立？ |
| 位 | 谁能说、能决定、能执行并承担责任；身份、位置、权限与责任是否相称？ |
| 中 | 言行是否过与不及；是否为爽点把惩罚、承诺、技术或情绪推到极端？ |
| 正 | 目的、手段、名义和事实是否互相支撑；好目标是否被用来遮蔽坏手段？ |
| 应 | 亲疏、上下、敌我、制度与普通人是否产生真实回应和反作用？ |
| 比 | 结盟、依附、亲近和边缘化是否有原因、选择和边界？ |
| 承 | 接令、接班、接物、接技术、接责任的人是否有能力真正接住？ |
| 乘 | 是否有人知小谋大、力少任重、越位驭强或能力不足却占关键位？ |
| 刚柔 | 坚持与调适是否配合；角色是否只有强硬或只有退让？ |
| 进退 | 何时该进、何时该退；调查、公开、追击、试验、关系推进是否有停止线？ |
| 动止 | 行动与等待分别基于什么条件；等待期间是否仍在侦察、准备和校正？ |
| 损益 | 谁得、谁失、谁维护；大局获益是否遮住了具体人的损失？ |
| 消长 | 优势、危机、声望、伤势、材料和制度如何逐步增减；转折是否有积累？ |
| 几微 | 最早信号在哪里；人物为何察觉、错过或无权处理？ |
| 变通 | 条件变化后方案是否改变；是否把一套办法写成永远有效？ |
| 始终 | 开端是否埋下终局条件；阶段完成后有无维护、反噬、交接和下一始？ |
| 诚孚 | 信任来自哪些可见行动、证据和共同承担；是否只靠口号？ |
| 言行 | 话是否合时、合位、合知、合责、合对象；话后是否有行动、传播与后果？ |

## 四、人物说话九慎

每个实质信息、判断、命令、承诺、威胁、劝告或定性，先做可留／慎留／禁留判断，再核：

1. **慎时**：为什么现在说；过早是否泄密，过迟是否误事？
2. **慎位**：此身份有资格命令、承诺、定性或公开吗？
3. **慎知**：来自亲见、听闻、文书、推断还是特殊能力；是否把推断说成定论？
4. **慎中**：长度、语气和确定度是否与证据、年龄和身体相称？
5. **慎正**：字面名义、真实目的与实际行动是否一致？
6. **慎应**：听者是否在场、听得懂、能复述并产生真实回应？
7. **慎密**：谁该知道多少；公开、私下、暂缓和泄露后果是否成立？
8. **慎诺**：人物有无权限、资源和时间兑现；说出口后是否形成责任？
9. **慎止**：何时应停、改口、承认不知或等待复核；沉默是否有动作与后果？

“说话留三分”不要求人物故作深沉、统一说半句话、堆省略号或背《周易》。身份低者的沉默可能来自压迫，反派的含蓄可能是操控；必须结合资格、动机与后果判断。

## 五、六十四卦卡的调用边界

1. 十八镜为全量最低检查；六十四卦卡只按对象真实问题选用。
2. 每个对象至少记录一个主触发卡和一个反向／制衡卡，说明它帮助发现了什么具体问题。
3. 重大转折、权力交接、战争、刑责、婚姻、制度改革、技术放大或灾害，至少交叉检查“时位、进退、损益、终始”。
4. 《序卦》只用于检查因果转承，《杂卦》只用于寻找相反力量，《说卦》只提供功能性动词与关系联想。
5. 禁止随机抽卡、按日期数字配卦、给人物贴固定卦型、用“吉凶无咎”替代因果，或把卦象对应物机械塞进场景。

详细索引见[周易思维小说复核库](11_周易思维小说复核库.md)。

## 六、证据位置与放行条件

项目化后固定建立`05_核验库/07_周易思维复核/第XX卷_卷名/`：

| 对象 | 最低文件 | 必须证明 |
|---|---|---|
| 卷纲 | `第XX卷_卷纲周易思维复核.md` | 整卷十八镜、主卡／制衡卡、关键言行分类、卷末接口 |
| 整卷细纲＋逐W | `第XX卷_细纲周易思维复核.md` | 整卷转承与每个W独立结论；禁止一句“全部通过” |
| W正文 | `WXXX_周易思维复核.md` | 当前W候选／最终SHA、老书虫全文核验前的复核时点、句号／场景问题与结论；后续若改文须对新SHA重做 |
| C正文 | `CXXX_周易思维复核.md` | 当前C候选／最终SHA、新章界下在老书虫全文核验前重新复核；不得继承W，后续若改文须对新SHA重做 |

正式复核使用[周易思维三阶段复核卡模板](../06_核验模板库/15_周易思维三阶段复核卡模板.md)。卷纲／细纲任一常规证据缺失、W／C未完成本轮周易前置复核、任一文件仍有`待核／需改／阻断`、对象SHA不一致，或正文最终SHA没有同时对应周易与全部下游核验证据时，当前阶段不得放行。

## 七、修改与闭环重核

卷纲与细纲使用下列闭环：

```text
完成常规核验 → 锁定对象SHA → 独立周易思维复核
→ 若不改对象且无阻断：记录通过
→ 若修改对象：旧SHA、旧常规结论和本次周易结论同时失效
→ 建修改记录并重做受影响的常规核验
→ 对最终SHA重新执行周易思维复核 → 两层均通过才放行
```

W正文与C正文使用下列闭环，顺序不得倒置：

```text
W成稿／C重组完成 → 锁定候选SHA → 独立周易正文复核
→ 周易通过 → 老书虫全文章节核验
→ 小白＋双词典＋全规则覆盖＋逐句核验
→ 若全程不改文且无阻断：该SHA成为最终SHA并放行
→ 若任一后续环节修改正文：建立修改记录；本轮周易卡及全部下游证据失效
→ 锁定新SHA → 先重做周易 → 再从老书虫全文核验起完整重核
→ 周易与全部下游证据均对应同一最终SHA，才可放行
```

周易复核只能加严项目规则，不能为人物在场、身体、知情、史实、医学、法律、技术、安全或作者裁决开后门。

## 八、旧对象追补

本规则生效前已标“通过”的卷纲、细纲、W或C，只能保留为旧口径常规通过。没有周易复核证据时，不得改写成“当前全规则通过”。追补必须锁定当前对象SHA，逐卷、逐W、逐C生成新证据，不倒填历史执行时间，不复制旧结论。
