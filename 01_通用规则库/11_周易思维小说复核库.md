# 周易思维小说复核库

> 用途：供所有题材小说的卷纲、细纲、W工作单元与C正式章作作者／审稿层复核。
> 不用于：起卦占断、预测作者或角色运势、把人物分成固定卦型、用卦名决定剧情、以古经替代项目事实和专业资料。
> 执行规则：[周易思维三阶段强制复核规则](10_周易思维三阶段强制复核规则.md)。

## 一、这套思维审什么

《周易》在本库中不是答案生成器，而是一组追问变化的方法：

1. 变化是否有条件、积累、转折、极限、回落和下一阶段；
2. 人物的时机、身份、身体、知情、权限与责任是否相称；
3. 关系、对手、制度、普通人和环境是否真实回应；
4. 推进、等待、退让、公开与停止是否有条件和边界；
5. 谁受益、谁受损、谁维护、谁承担失败；
6. 大事前是否有几微信号，人物为何看见或错过；
7. 阶段完成是否被误写成最终完成，交接、反噬和维护是否存在；
8. 话是否合时、合位、合知、合责、合对象，且说后有行动与后果；
9. 技术、制度和组织是否根据现场反馈变通，而非“出现即成熟”；
10. 思想是否落到场景、动作、选择、代价和接口，而非宏大旁白。

固定变化链：

```text
几微信号
→ 察觉或错过
→ 试探／等待／准备
→ 有限行动
→ 他人和环境响应
→ 调整、进退或止损
→ 阶段结果
→ 维护、反噬和下一始
```

## 二、经传到小说复核的五层读法

1. **先守项目事实**：先核作者裁决、母纲、年表、人物卡、研究资料、细纲和当前SHA；项目硬事实不成立时直接退回。
2. **再看时与位**：同一行动由不同身份、在不同阶段作出，权限、意义和后果不同。
3. **再看关系与响应**：行动必须进入关系网；“应”不是全世界赞同主角，而是产生真实回应和反作用。
4. **再看变化与分寸**：变化不能无前因跳变，也不能以“恒”为名僵死；要写出条件、反馈和调整。
5. **最后看言行与后果**：先判能不能留，再核时、位、知、密、诺、止；谨慎不等于吞吐、古雅或沉默。

## 四、经传专项复核

### 4.1 《系辞》十二问

观象与观变是否分开；错误怎样补过；成长是否产生新责任；重大言行是否先拟议；一句话怎样改变信任与行动；秘密是否分级保管；方法迁移前是否检查条件；知识是否进入器物与程序；旧办法如何穷、怎样变、为何通、如何久；何时藏器待时；安定时是否预见危险；几微信号为何被察觉或错过。

### 4.2 《说卦》八个功能词

| 功能 | 用于复核 | 禁止机械化 |
|---|---|---|
| 健 | 发动、持续、担当 | 不等于男性、皇帝或永远强攻 |
| 顺 | 承载、配合、落实 | 不等于女性顺从或没有主见 |
| 动 | 突发、唤醒、启动 | 不等于必须写雷 |
| 入 | 渐入、渗透、反复申命 | 不等于软弱或风景描写 |
| 陷 | 风险、重复险境、通道 | 不等于必须写水 |
| 丽 | 依附、照明、辨明 | 不等于必须写火或美貌 |
| 止 | 边界、暂停、止损 | 不等于人物僵住不动 |
| 说 | 沟通、悦服、讲习 | 不等于人人高兴或靠嘴取胜 |

### 4.3 《序卦》转承六问

上一状态为何产生下一问题；转折来自积累、冲击、选择还是反作用；是否缺过桥事件、时间、资源或传播；还有哪些可能路径；卷末状态能否发动下一卷；若项目事实指向不同路径，是否服从项目事实。

### 4.4 《杂卦》反向检查

主动寻找刚／柔、忧／乐、起／止、进／退、聚／散、损／益、通／塞、明／伤、既济／未济等成对力量。每个高潮至少问：“反过来看，谁正在承担被忽略的一面？”这不是强行各打五十大板，而是防止单一胜者视角。

## 七、禁止“易经味”误用

1. 旁白直接宣布“物极必反”“否极泰来”，却没有反作用和人物选择；
2. 所有人逢决策都背卦辞，且不符合学养、场合和声线；
3. 把刚柔写成固定性别，把乾坤写成固定人格或等级；
4. 把顺势写成宿命、谨慎写成拖延、中道写成不分是非；
5. 六十四卦机械对应六十四章、天气、人物或输赢；
6. 只选支持现有方案的卡，不主动寻找失败条件和被忽略代价；
7. 报告写得玄奥，却没有对象路径、SHA、场景／句号、修改和重核。
