# 模板变量与命名规范

## 一、固定变量

| 变量 | 含义 | 示例格式 |
|---|---|---|
| `{{书名}}` | 小说正式名 | 不含书名号 |
| `{{项目根目录}}` | 新项目绝对路径 | Windows绝对路径 |
| `{{卷号}}` | 两位卷号 | `01` |
| `{{卷名}}` | 当前卷动态名称 | 由卷纲决定 |
| `{{工作单元号}}` | 三位工作单元号 | `W001` |
| `{{章号}}` | 三位正式章号 | `001` |
| `{{章名}}` | 正式章动态标题 | 内容完成后生成 |
| `{{人物名}}` | 人物正式称呼 | 不用占位名交付 |
| `{{正式章字数下限}}` | 有效正文下限 | 由作者裁决 |
| `{{正式章字数上限}}` | 有效正文上限 | 由作者裁决 |
| `{{卷末标记}}` | 最后一章标题后缀 | 由作者裁决 |
| `{{当前日期时间}}` | 存证时间 | `YYYY-MM-DD HH:mm:ss` |

## 二、命名规则

- 卷纲：`第{{卷号}}卷_{{卷名}}.md`
- 细纲：`第{{卷号}}卷_{{卷名}}.md`
- 工作单元：`WXXX_工作名.md`
- 正式章：`第XXX章_{{章名}}.md`
- 覆盖卡：`WXXX_全规则覆盖卡.md`或`CXXX_全规则覆盖卡.md`
- 逐句表：`WXXX_逐句核验表.md`或`CXXX_逐句核验表.md`
- 修改记录：`WXXX_修改记录.md`或`CXXX_修改记录.md`
- 卷终卡：`第{{卷号}}卷_全卷连续性与规则总核验表.md`

## 三、替换规则

1. 只在新项目副本中替换变量，不改通用模板原件。
2. 路径统一使用项目内相对路径；只有唯一入口和必要的运行说明可登记绝对根目录。
3. 变量不能被空字符串替换；尚未决定写`TX待作者裁决`。
4. 正式章名、卷名不得在内容完成前锁死；工作名只是内部说明。
5. 重命名后必须同步正文标题、索引、核验卡、TXT配置和所有链接。
