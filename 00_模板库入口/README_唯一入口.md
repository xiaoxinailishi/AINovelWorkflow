# 小说通用模板库唯一入口

> 本目录是所有长篇小说可复用的写作、核验与存证模板库，不属于任何一本具体小说。  
> 模板变量统一写成`{{变量名}}`。建立新书时应复制模板，不得把具体小说正文、人物或作者裁决反写进本模板库。

AI或Codex调用本库时，根目录[SKILL执行入口](../SKILL.md)负责强制前置自检、阶段路由和完成闸门，但不能替代本文件、规则全文或项目现行入口。本文件仍是磁盘执行的唯一第一入口。

## 一、第一次使用的固定顺序

1. 完整阅读[通用模板库完整交接文档](10_通用模板库完整交接文档.md)，先理解全库层级、文件关系、Obsidian用法和逐卷到结局的完整循环。
2. 用[新手快速启动与轻量练习路径](11_新手快速启动与轻量练习路径.md)选择轻量练习稿、正式短篇或严肃长篇；选择只改变执行路径，不改变作者最终裁决权。
3. 正式短篇或严肃长篇完整阅读[新小说初始化顺序](01_新小说初始化顺序.md)。
4. 完整阅读[通用文件链路图](02_通用文件链路图.md)。
5. 正式项目复制`03_新书项目骨架`到新书目录，替换全部模板变量。
6. 将`01_通用规则库`和`02_语言与风格库`复制进正式项目规则库。
7. 将03、04、05、06号入口文档中的4份现行流程硬规则迁入正式项目入口；推荐用初始化脚本一次完成第6、7步并核对SHA。
8. 将`04_写作模板库`、`05_人物与设定模板库`、`06_核验模板库`复制到正式项目对应位置。
9. 按[每卷严格生产流程](03_每卷严格生产流程.md)工作，不得越级生成正文。

| 严肃长篇 | 本文件＋完整交接＋逐卷全流程 | 逐W、逐C、逐卷核验并由作者扶正 |

协作前用[常见协作模式配置模板](../06_核验模板库/14_常见协作模式配置模板.md)明确谁写、谁核、谁放行和谁回写。发生规则冲突、事实矛盾、时间线错位、误覆盖、证据失效或越权操作时，立即执行[失败模式与恢复手册](12_失败模式与恢复手册.md)，恢复完成前禁止继续生产。

完整资产范围见[通用资产清单](08_通用资产清单.md)；逐层“已放／此次补放／故意不放／仍待裁决”状态见[完整资产登记与缺口清单](09_完整资产登记与缺口清单.md)。

## 三、不可跳过的原则

- 作者最新明确裁决高于一切模板，但必须写入项目专属规则，不得只留在聊天里。
- 新窗口不得凭聊天记忆写作，必须从项目唯一入口进入。
- 规则总索引登记的每份规则，对每个工作单元和正式章都要从首行读到末行并判断适用性。
- 通用规则库和语言库必须整层迁移并逐文件核对SHA；不得选读、摘要迁移或凭旧窗口记忆补规则。
- 卷纲和逐工作单元细纲未通过核验，不得生成正文。
- 每卷卷纲常规检查后、整卷与逐W细纲常规核验后，必须对当前最终SHA执行独立周易思维复核；每个W成稿和每个C重组完成后，则必须先锁候选SHA完成周易正文复核，通过后才允许进入老书虫全文章节核验及其后的小白、双词典、全规则覆盖与逐句核验。不得起卦占断、机械配卦，或用“说话做事一律留三分”代替可留／慎留／禁留的事项判断。
- 工作单元通过，不等于正式章通过；正式章重组后必须重新核验。
- 机械脚本只能检查结构、数量、哈希和链接，不能代替人工阅读与语义判断。
- 作者未明确扶正，正文不得进入正式正文库。
- 每次写文件、改正文、生成核验结论或报告完成前，必须确认当前授权、对象、阶段、上游版本、必读文件、阻断项和回写对象；任一不明只能补读取或报告，不能继续生产。
- 不得设置能被误报为正式完成的“快速模式”。用户只要草稿时必须明确标记未完成正式核验，不生成虚假通过证据，也不进入正式正文库。
- 语义正文、关键因果、逐句判断、全规则适用判断和最终验收由主写窗口负责；并行协作只限作者允许的机械或独立资料任务，其结论不得直接继承为正式通过。
- 轻量练习稿只是降低交付层级，不是正式项目的快捷验收；升级时必须补齐全套规则与证据，并从首章重新核验。
- 失败恢复必须先保留故障现场、失效旧证据并定位最后有效SHA；不得静默覆盖错误后继续生产。

| 卷纲定稿前 | 卷纲常规检查记录、卷纲周易思维复核 | 卷纲原目录；`05_核验库/07_周易思维复核/第XX卷_卷名/第XX卷_卷纲周易思维复核.md` |
| 细纲放行前 | 细纲规则核验卡、整卷＋逐W周易思维复核 | `05_核验库/01_细纲核验/...`；`07_周易思维复核/第XX卷_卷名/第XX卷_细纲周易思维复核.md` |
| W写前 | 当前W全规则覆盖卡，并完成写前基线、规则与正文SHA、人物在场／身体／知情、物件与任务领取、双词典风险、回写对象 | `05_核验库/02_全规则覆盖/第XX卷_卷名/工作单元WXXX_全规则覆盖卡.md` |
| W写中 | W正文；同一W覆盖卡写中区同步记录双词典风险与处理位置 | `02_写作库/06_当前卷执行包/第XX卷_卷名/01_工作单元/WXXX_工作名.md`；覆盖卡仍在上行目录 |

每一阶段必须读取的完整来源、精确文件名和放行条件，以[每卷严格生产流程第三节](03_每卷严格生产流程.md#三阶段输入输出和闸门)为准。周易复核的固定方法、十八镜、人物说话九慎、六十四卦问题索引和独立卡见[周易思维三阶段强制复核规则](../01_通用规则库/10_周易思维三阶段强制复核规则.md)、[周易思维小说复核库](../01_通用规则库/11_周易思维小说复核库.md)与[周易思维三阶段复核卡模板](../06_核验模板库/15_周易思维三阶段复核卡模板.md)。任一必需文件不存在、放错目录、文件名不符合规范、内容为空、仍含`待核／待填／需改／阻断／TX待作者裁决`、SHA不一致、缺业务关联或缺反向入口，或卷纲、整卷细纲＋逐W、当前W、当前C缺周易复核，本工作单元、本正式章或本卷一律禁止提交验收。修改记录与题材任务卡只在实际改文或触发相应题材时强制建立，未触发不得虚建空文件；W／C在周易之后的任一核验只要改文，本轮周易卡及全部下游证据均失效，必须对新SHA先重做周易，再从老书虫全文核验起重做全部下游核验。

## 四、新项目必须新增的内容

通用模板不能替代项目专属规则。每本书至少要补：

- 作者最高裁决与禁写项；
- 世界观、时间线、事实与架空边界；
- 主角能力或金手指边界；
- 人物关系、称谓和声线；
- 题材专项规则；
- 正式章字数、卷末标记、标题偏好；
- 本书禁用词、偏好词和参考文本边界。
